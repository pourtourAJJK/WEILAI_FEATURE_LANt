# Product Brief: FocusFlow — 智能待办清单与番茄钟专注计时工具

## Executive Summary

FocusFlow 是一款面向学生群体的轻量化、免安装、纯前端 Web 工具，将**待办任务管理**与**番茄钟专注计时**深度联动，帮助用户在任务繁杂、注意力易分散的日常学习场景中，以番茄工作法驱动任务完成，以任务清单锚定专注方向。工具无需账号注册、无需后端服务器，所有数据通过浏览器 LocalStorage 本地持久化，打开即可使用，刷新不丢失。

## The Problem

当代大学生日常面临"多线作战"：课程作业、小组项目、考试复习、社团事务同时堆积。常见痛点：

1. **任务清单与计时工具割裂**：用 A 应用记待办、B 应用计时间，两边数据互不相通，无法知道"这个任务花了多少个番茄才做完"。
2. **市面应用功能冗余**：Todoist、滴答清单等主流应用有账号体系、云同步、广告推送、社区社交等学生不需要的重功能，启动重、操作复杂。
3. **缺少正反馈闭环**：专注完成后没有"视觉奖励"或"累计番茄数"的成就感，难以坚持使用番茄工作法。
4. **数据不自由**：若依赖云服务，换电脑、断网或服务停用时数据不可控。

## The Solution

FocusFlow 将**任务清单**作为专注的"启动锚点"，将**番茄钟**作为任务的"完成引擎"，两者在一个页面内完成联动：

- 用户在左侧列表中选中一个待办任务 → 右侧番茄钟自动关联该任务 → 点击开始 → 25 分钟倒计时 → 结束时自动记录"该任务 +1 个番茄" → 短休息 / 长休息循环
- 顶部统计卡片实时展示今日专注时长、番茄完成数、已完成任务数
- 设置面板允许用户自定义学习/休息时长，无需学习成本，打开即用

## What Makes This Different

| 维度 | FocusFlow | 市面主流应用 |
|------|-----------|-------------|
| 部署 | 纯前端静态 HTML，双击即可 | 需安装 App / 需登录账号 |
| 数据 | LocalStorage 本地存储，完全自主 | 云端服务器，依赖网络 |
| 功能耦合 | 任务 ↔ 番茄钟 深度联动 | 清单与计时多为独立模块 |
| 广告 | 零广告 | 免费版普遍有广告 |
| 目标用户 | 聚焦学生学习场景 | 泛用白领/自由职业者 |

## Who This Serves

**主要用户：在校大学生（18-25 岁）**
- 每天有 3-10 个待办学习任务需要安排
- 希望用番茄工作法提升专注度，但现有工具太复杂
- 不希望注册账号、不希望被广告打扰
- 习惯用浏览器打开网页使用轻量工具

**次要用户：需要短时专注的自由职业者 / 研究生**

## Success Criteria

- 用户打开页面后，**30 秒内**能添加一个任务并启动一次番茄钟
- 番茄结束提醒**声音 + 视觉提示**清晰可闻
- 连续使用一周后，用户能在统计面板看到**累计番茄数 ≥ 10**
- 页面在本地浏览器刷新后**所有数据完整恢复**

## Scope

### In Scope (v1)
- 待办任务的增删改查 + 完成标记 + 状态筛选
- 番茄钟三种模式（学习 25min / 短休息 5min / 长休息 15min）
- 任务与计时的联动绑定
- 基础数据统计面板（今日专注时长、番茄数、完成任务数）
- 设置面板自定义时长参数
- LocalStorage 自动保存

### Explicitly Out of Scope (v1)
- 账号系统 / 云同步
- 移动端原生 App（仅响应式网页）
- 团队协作 / 多人共享
- 任务优先级排序算法（手动拖拽或标记即可）
- 深色模式（v2 考虑）
- 导出数据（CSV / JSON）

## Vision

若 v1 成功，FocusFlow 可向以下方向演进：
1. v2：加入深色模式、数据导出、任务拖拽排序、连续专注天数统计（Streak）
2. v3：支持 PWA 离线安装、Chrome 扩展形态
3. 长期：与课程管理系统（如 Moodle / Canvas）对接，自动同步作业截止日期
